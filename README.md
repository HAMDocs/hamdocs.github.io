# Preceptor.IA — aplicação publicada

Este repositório contém **apenas o app compilado** (HTML/CSS/JS gerado pelo
build). O código-fonte fica no repositório privado `preceptor-ia`.

Publicado em: https://gustavosamu.github.io/preceptor-ia-app/

Nenhuma chave secreta vive aqui: o app usa a chave *publicável* do Supabase,
que é pública por desenho e protegida por RLS no banco. As chaves da Anthropic
e a service key existem apenas nas edge functions do Supabase.
